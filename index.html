StreamerClipsBot

StreamerClipsBot is a Windows desktop tool for creating short clips from livestreams with the permission of the respective creators. It can add subtitles and prepare clips for review before publication.

How it works

The user selects authorized livestream channels. The software captures permitted streams, creates short clips, and prepares them for manual review. Publication is not automatic.

Creator rights

Only content that the user is authorized to use should be processed. StreamerClipsBot does not claim ownership of third-party content.
